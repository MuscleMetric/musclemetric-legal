Workout logging guide

How to track sets, reps and weight without turning training into admin.

The simplest useful strength-training log records the exercise, each completed set, the reps performed and the weight used. The real value comes later: keeping those numbers attached to the workout date and exercise history so you can compare sessions instead of relying on memory.

Quick answer

What should you record?

  • Exercise name
  • Completed sets
  • Reps completed in each set
  • Weight used for each set
  • Useful notes when context changed
The minimum useful log

Start with the numbers you can reliably record every session.

More data is not automatically better. If a logging system is too slow to use between sets, it stops being useful. For most resistance-training sessions, sets, reps and weight create a strong baseline because they describe the work completed and are easy to compare with the next session.

Sets

A set groups one continuous bout of an exercise. Recording completed sets makes it possible to compare total work from one session with another.

Reps

Repetitions show how much work was completed inside each set. Recording the actual number matters more than assuming the planned target was achieved.

Weight

Load gives the reps context. The same number of reps with a different weight can represent a meaningfully different performance.

During the workout

Log the completed set while the information is still fresh.

A practical workflow is to keep the next planned target visible, complete the set, then record what actually happened during the normal rest period. If the target was 80 kg for 8 reps but you completed 80 kg for 7, the history should contain 7. The completed workout is more useful when it reflects performance rather than the original plan.

Keep extra notes short and purposeful. A note can be useful when technique, equipment, exercise variation or another clear piece of context changed. The goal is not to write a diary between every set.

Example

What a useful set history looks like.

Imagine a bench-press session with a target of three working sets at 80 kg. A useful workout log might record 8, 8 and 7 reps. On the next bench session, those exact numbers give you a reference point. You can compare performance without trying to remember whether the previous final set was seven or eight reps.

After the session

The workout log becomes useful when you can find it again.

A list of numbers with no history is only a temporary record. Keep completed sets attached to the workout date and exercise so the next session can answer simple questions quickly: What did I do last time? Did the load change? Did the reps change? How many sessions have I completed recently?

Choosing a method

Notes, spreadsheets or a workout tracker app?

A notes app is quick to start but usually requires manual organisation when you want to compare exercises later. A spreadsheet can be flexible and powerful, but entering data on a phone during a live gym session may take more effort. A workout tracker is designed around repeated exercise and set entry, so the trade-off is less setup and more structure.

The best option is the one you will use consistently and can understand later. If your current method already gives you fast logging, clear history and useful comparisons, changing tools for the sake of changing tools will not improve your training record.
